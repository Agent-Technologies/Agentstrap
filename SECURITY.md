# Security Policy

## Version Support
When Version 3.x.x comes out, we will drop support for 1.x.x.

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.x.x   | :white_check_mark: |
| 1.x.x   | :white_check_mark: |

## Reporting a Vulnerability

To report a Vulnerability, please do NOT send it in issues, as that will allow people to find the vulnerability faster.
Instead, report it to:

agenstrap@proton.me
